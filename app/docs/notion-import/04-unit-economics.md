# Fenix — Economía unitaria

> Todos los números de coste son **PROVISIONAL** hasta confirmar proveedor.

## Metas

- AOV (ticket medio) ≥ **USD 35**.
- Coste total (producto + envío) ≤ **35%** del precio.
- Margen bruto ≥ **50%**.
- Markup ≥ **3x**.
- Break-even CAC = margen bruto por pedido.

## Ejemplo con precio de USD 39 (estándar)

| Concepto | Valor (ejemplo) | Nota |
| --- | --- | --- |
| Precio de venta | 39.00 | AOV objetivo |
| Coste producto (COGS) | 9.00 | PROVISIONAL |
| Coste envío (a cliente) | 4.00 | PROVISIONAL |
| **Margen bruto** | **26.00** | 66.7% del precio |
| Markup | 4.3x | (39 / 9) sobre COGS |
| Break-even CAC | 26.00 | Igual al margen bruto |
| Comisión pasarela (~3%) | 1.17 | Estimado |
| **Margen neto (sin CAC)** | **24.83** | |

> Ajustar cuando se conozcan costes reales. Si el margen bruto baja de 50%, subir precio, cambiar proveedor o reducir coste de envío (bundles, envío combinado).

## Métricas que importan (primeros 90 días)

- **Contenido:** ≥ 2 posts/día (TikTok + Pinterest).
- **Tráfico:** sesiones/semana en tendencia; registrar los 3 mejores hooks.
- **Conversión:** add-to-cart ≥ 5%; finalización de checkout ≥ 40%.
- **Postventa:** devoluciones/reembolsos < 8%; vigilar recompra.

## Cómo calcular con datos reales

1. Rellena coste unidad y coste envío del proveedor elegido.
2. Precio = coste total / 0.35 (para dejar el coste en 35% y margen en 65%).
   - Ejemplo: coste total 13 → precio ≈ 37; redondear a 39.
3. Verifica que markup ≥ 3x y margen ≥ 50%.
4. Define break-even CAC = margen bruto.
